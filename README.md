## 🌐 APIs Used

- **Weather Forecast & Conditions**: [Open-Meteo Forecast API](https://open-meteo.com/en/docs)
- **City Search & Geocoding**: [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api)
- **Reverse Geolocation**: [BigDataCloud Reverse Geocoding Client](https://www.bigdatacloud.com/)

All APIs used are completely free, open, and require no API key or authentication tokens.
